# 코인 자동매매 봇 — 사용 설명서

OrangeX 거래소에서 "마틴게일식 격자 분할매수" 전략을 자동으로 실행해주는 프로그램입니다.
이 문서는 컴퓨터나 프로그래밍을 잘 몰라도 처음부터 끝까지 따라 할 수 있도록 순서대로 정리했습니다.

---

## ⚠️ 0. 시작하기 전에 반드시 읽어주세요

- **이 프로그램은 실제 돈으로 거래할 수 있습니다. 잘못 설정하면 돈을 잃을 수 있습니다.**
- **절대로 "실전 매매"부터 시작하지 마세요.** 반드시 "연습 모드"로 며칠 이상 지켜보면서
  화면에 나오는 동작이 이해되고 이상이 없는지 확인한 뒤에만 실전으로 넘어가세요.
- 실전 매매에서는 처음에는 **잃어도 크게 상관없는 아주 작은 금액**으로만 시작하세요.
- 아래 "6. 아직 구현되지 않은 안전장치" 항목을 꼭 읽어주세요 — 이 프로그램이
  **아직 막아주지 못하는 위험**이 있습니다.
- 이 프로그램을 만든 사람(개발자)도, 이 문서를 작성한 AI도 여러분의 투자 결과를
  책임지지 않습니다. 모든 판단과 책임은 사용하는 사람에게 있습니다.

## 1. 준비물

- Windows 컴퓨터 (10 또는 11)
- 인터넷 연결
- OrangeX 거래소 계정 + 그 계정의 **API 키** (아래 "2. 최초 설정"에서 발급 방법 설명)
- (실전 매매를 할 경우) 거래소 계좌에 입금된 자금

## 2. 최초 설정 (한 번만 하면 됩니다)

### 2-1. 프로그램 설치

1. 이 프로젝트 폴더 안의 **`install.bat`** 파일을 더블클릭하세요.
2. 검은 화면(명령 프롬프트)이 뜨고 자동으로 설치가 진행됩니다. 처음 실행할 때는
   몇 분 정도 걸릴 수 있습니다.
   - 만약 "Python was not found" 라는 메시지가 뜨면, 이 컴퓨터에 Python이 설치되어 있지
     않은 것입니다. [python.org/downloads](https://www.python.org/downloads/) 에서
     Python 3.11 이상을 내려받아 설치하세요. **설치 화면에서 "Add python.exe to PATH"
     체크박스에 반드시 체크**해야 합니다. 설치 후 `install.bat`을 다시 실행하세요.
3. 설치가 끝나면 메모장이 자동으로 열립니다 — 이게 설정 파일(`.env`)입니다.

### 2-2. 거래소 API 키 발급받기

1. OrangeX 웹사이트/앱에 로그인합니다.
2. API 관리(API Management) 메뉴로 들어갑니다.
3. 새 API 키를 발급받습니다. 이때 **거래(Trade) 권한을 켜야** 봇이 실제로 주문을 넣을 수
   있습니다. **출금(Withdraw) 권한은 절대 켜지 마세요** — 봇에게 그 권한은 필요 없고,
   키가 유출됐을 때 피해를 줄이기 위한 안전장치입니다.
4. 발급된 **API 키(Key)**와 **API 시크릿(Secret)**을 복사해둡니다. (시크릿은 한 번만
   보여주는 경우가 많으니 그 자리에서 바로 복사하세요.)

### 2-3. 메모장에 붙여넣기

`install.bat`이 열어준 메모장(`.env` 파일)에서 아래 두 줄을 찾아 값을 채웁니다.

```
API_KEY=여기에_API_키_붙여넣기
API_SECRET=여기에_API_시크릿_붙여넣기
```

나머지 항목은 일단 기본값 그대로 두어도 괜찮습니다. 각 항목이 무슨 뜻인지는
"5. 설정 항목 설명"을 참고하세요. 다 채웠으면 **저장(Ctrl+S)** 하고 메모장 창을 닫습니다.

> 이 `.env` 파일은 절대 다른 사람에게 보여주거나 카카오톡/이메일 등으로 전송하지 마세요.
> API 키가 그대로 노출되면 다른 사람이 여러분의 계정으로 거래할 수 있습니다.

## 3. 실행 방법

1. **`run.bat`** 파일을 더블클릭합니다.
2. **[0] 무엇을 할까요?** 먼저 묻습니다. 방향키(↑/↓)로 항목을 옮기고 **Enter**로
   선택하세요.
   - `1. 봇 실행` — 아래 자동매매 흐름으로 이어집니다.
   - `2. 즉시 진입` — 자동매매와 별개로, 지금 바로 지정가 매수/매도 주문을
     여러 개 한 번에 걸어두는 수동 도구입니다. 아래 "3-1. 즉시 진입" 참고.
3. `1. 봇 실행`을 고르면 아래와 같은 질문이 순서대로 나옵니다. 마찬가지로
   방향키로 옮기고 Enter로 선택하면 됩니다.

   **[1] 실행할 모드를 선택하세요.**
   - `1. 연습 모드` — 가상의 돈으로만 동작합니다. 실제 주문이 전혀 나가지 않습니다.
     **처음에는 무조건 이걸 선택하세요.**
   - `2. 실전 매매` — 실제 돈으로 거래소에 진짜 주문을 넣습니다. 선택하면 정말 시작할
     건지 한 번 더 물어봅니다(`실행` 이라고 직접 타이핑해야 진행됩니다).

   **[2] 청산(익절/손절) 방식을 선택하세요.**
   - `1. 완전 자동` — 추천하는 방식입니다. 매수 조건 확인, 매수/매도, 목표가 도달 시
     익절, 손절까지 전부 봇이 알아서 처리합니다.
   - `2. 진입만 자동, 청산은 직접` — 조건을 따지지 않고 즉시 매수/매도만 자동으로 하고,
     언제 얼마에 팔지(익절/손절)는 사용자가 거래소 앱에서 직접 정해야 합니다. 이 옵션을
     고르면 봇은 매수/매도 체결 외에는 아무것도 자동으로 하지 않습니다 — **익절/손절
     주문은 반드시 거래소에서 직접 걸어두세요.**

4. 이후 화면에 계속 진행 상황이 표시됩니다. **끄고 싶으면 이 창을 그냥 닫지 말고,
   창 안을 한 번 클릭한 뒤 `Ctrl + C`를 눌러주세요.** (그냥 창을 닫으면 프로그램이
   비정상적으로 종료될 수 있습니다.)

## 3-1. 즉시 진입 ("숏!"/"롱!")

`run.bat` 첫 화면에서 `2. 즉시 진입`을 고르면 나오는 도구입니다. 자동매매 봇(위
3번)과 완전히 별개로 동작하며, **현재가부터 시작해서 `GRID_TICK` 간격으로,
지정한 가격 범위까지 지정가 매수/매도 주문을 한 번에 여러 개 걸어둡니다.**

- 방향(숏/롱)과 **진입 범위**(현재가 기준 ±USDT — `3,000 USDT`/`5,000 USDT`/직접
  입력)를 물어봅니다. **이 금액은 증거금이 아니라 가격 범위입니다** — 예를 들어
  현재가가 62,000이고 범위를 3,000으로 고르면, 65,000(숏 기준)까지 `GRID_TICK`
  (기본 50 USDT) 간격으로 60개 주문이 걸립니다. 주문 1개당 증거금은 `QUICK_ENTRY_
  CHUNK_USDT`(기본 50 USDT, 범위와 무관하게 고정)로 정해집니다.
- 실행 직전 화면에 `주문 O개, 개당 증거금 O USDT (총 증거금 O USDT, 레버리지 Ox)`
  형태로 미리보기가 표시됩니다 — 실전 매매라면 이 숫자를 꼭 확인하세요.
- **진입 주문만 자동으로 걸립니다 — 익절/손절은 절대 자동으로 걸리지 않습니다.**
  `2. 진입만 자동, 청산은 직접`(위 5번 표의 `MANUAL_MODE`)과 동일하게, 반드시
  거래소 앱에서 직접 익절/손절을 설정하세요.
- 실전 매매를 고르면 자동매매와 동일하게 `실행`이라고 직접 타이핑해야 진행되는
  확인 절차가 있습니다. **먼저 연습 모드로 결과(주문 개수/가격)를 확인해보는 걸
  권장합니다.**
- 한 번에 걸 수 있는 주문 개수는 최대 100개입니다(범위가 `GRID_TICK × 100`을
  넘으면 범위를 줄이거나 `GRID_TICK`을 키우라는 안내와 함께 거부됩니다).
- 주문이 걸릴 때마다 로그에 레버리지/매수·매도가/진입 마진이 함께 표시됩니다.

## 4. 화면에 나오는 내용 읽는 법

봇은 아래 순서로 상태가 바뀌면서 동작합니다. 로그에 이 이름들이 그대로 나옵니다.

| 상태 | 의미 |
|---|---|
| `IDLE` | 대기 중 (아직 아무것도 안 함) |
| `SCOUTING` | 진입해도 좋은 시점인지 확인 중 (RSI 지표 확인) |
| `LADDERING` | 격자 매수 진행 중 (가격이 떨어지면서 여러 번 나눠 사는 중) |
| `TP_PENDING` | 다 사고 나서 목표가(익절가) 도달을 기다리는 중 |
| `CLOSING` | 청산(매도) 처리 중 |
| `COOLDOWN` | 한 사이클이 끝나서 재진입을 잠시 쉬는 중 (기본 30분) |

- `RSI(14)=41.65 — long 진입 조건(≤30) 미충족, 계속 대기` 같은 문구는 **정상**입니다.
  아직 사라는 신호가 안 나왔다는 뜻입니다.
- 화면에 빨간 글씨나 `오류`, `실패`, `halted`, `Error` 같은 단어가 보이면 아래
  "문제가 생겼을 때"를 확인하세요.

## 5. 설정 항목 설명 (`.env` 파일)

| 항목 | 의미 | 주의사항 |
|---|---|---|
| `EXCHANGE` | 사용할 거래소 | 지금은 `orangex`만 지원 |
| `TRADING_MODE` | `paper`(연습) / `live`(실전) | **`run.bat`을 쓰면 매번 물어보므로 이 값을 직접 안 고쳐도 됩니다** |
| `API_KEY` / `API_SECRET` | 거래소 API 키 | 절대 남에게 노출 금지 |
| `SYMBOL` | 거래할 종목 | 기본값 `BTC-USDT-PERPETUAL` (비트코인) |
| `DIRECTION` | `long`(상승 베팅) / `short`(하락 베팅) / `both`(둘 다 동시에) | `both`는 아래 참고 |
| `EQUITY_USDT` | 이 전략에 배정할 자금(USDT) | 실제 계좌 잔고와 맞춰서 설정하세요. `DIRECTION=both`면 이 금액을 반으로 나눠 롱/숏에 각각 배정합니다 |
| `LEVERAGE` | 레버리지 배수 | 높을수록 위험합니다 |
| `GRID_TICK` | 격자 한 칸의 가격 간격 | 기본값(50)은 비트코인 기준값입니다 |
| `MAX_STAGE` | 최대 몇 단계까지 나눠 매수할지 (1~5) | 낮을수록 보수적입니다 |
| `MANDATORY_SL_MIN_TIER` | 몇 단계부터 거래소에 강제 손절(SL)을 걸지 | **`MAX_STAGE`와 반드시 맞춰야 합니다** — 예: `MAX_STAGE=3`이면 이 값도 3 이하여야 손절이 걸립니다. 이 값이 `MAX_STAGE`보다 크면 손절이 영원히 등록되지 않습니다 |
| `DAILY_LOSS_LIMIT_PCT` | 일일 손실 한도(%) | ⚠️ **아직 이 값은 실제로 동작하지 않습니다** (아래 6번 참고) |
| `COOLDOWN_MINUTES` | 한 사이클이 끝난 뒤 쉬는 시간(분) | |
| `MANUAL_MODE` | 청산 자동/수동 여부 | **`run.bat`을 쓰면 매번 물어보므로 이 값을 직접 안 고쳐도 됩니다** |
| `QUICK_ENTRY_CHUNK_USDT` | "즉시 진입"(3-1번) 주문 1개당 증거금 | 기본값 50 USDT |

**`DIRECTION=both`(롱/숏 동시 운용) 사용 시 주의사항**:
- 거래소 계좌가 **헤지 모드**(포지션 모드가 "One-way"가 아니라 "Hedge")로 설정돼 있어야 합니다. OrangeX 앱에서 해당 종목의 포지션 모드를 미리 확인하세요.
- `EQUITY_USDT`를 반으로 나눠 쓰기 때문에, **필요한 최소 자금이 단일 방향일 때보다 대략 2배** 필요합니다. 부족하면 봇이 시작 자체를 거부합니다(최소 주문 수량 미달).
- 지금은 `run.bat`의 대화형 메뉴에 이 옵션이 없습니다 — `.env` 파일을 직접 열어 `DIRECTION=both`로 바꿔야 켜집니다.

## 6. 아직 구현되지 않은 안전장치 (반드시 알아두세요)

이 프로그램은 아직 개발이 완전히 끝나지 않았습니다. 특히 아래 안전장치들은
**설정 파일에 항목만 있고 실제로는 동작하지 않거나, 아예 구현되지 않았습니다**:

- **일일 손실 한도(킬 스위치)**: `.env`의 `DAILY_LOSS_LIMIT_PCT`에 값을 넣어도
  손실이 그 이상 나도 봇이 멈추지 않습니다.
- **청산가 근접 경보**: 가격이 강제청산가에 가까워져도 별도로 알려주지 않습니다.
- **잔고 실시간 재검증**: 매수 직전에 실제 거래소 잔고를 다시 확인하지 않습니다.
- **API 키 권한 확인**: 실수로 출금 권한이 켜진 키를 써도 시작 시 막아주지 않습니다
  (그래서 위 2-2 단계에서 발급 시 직접 꺼야 합니다).
- **가격 급변 방어**: 가격이 순간적으로 비정상적으로 튀어도 별도로 막지 않습니다.

**즉, 지금 이 프로그램을 안전하게 지켜주는 것은 사용자가 `.env`에 신중하게 넣는
`EQUITY_USDT`(투입 자금), `LEVERAGE`(레버리지), `MAX_STAGE`(최대 단계) 값 자체와,
사용자가 직접 주기적으로 화면/거래소 앱을 확인하는 것뿐입니다.** 자리를 오래 비울
계획이라면 특히 신중하게 판단하세요.

## 7. 문제가 생겼을 때

### 봇이 스스로 멈췄어요 ("정지"/"halted" 관련 메시지가 보여요)

이 봇은 손절(SL) 주문 등록에 실패하는 것처럼 **위험한 상황을 만나면 일부러 스스로
멈추고 다시 켜져도 자동으로 재개하지 않도록** 설계되어 있습니다. 이럴 땐:

1. **거래소 앱에 직접 로그인해서** 지금 보유 중인 포지션과 미체결 주문을 눈으로 확인하세요.
2. 문제가 없다고 확인했다면, 프로젝트 폴더 안의 `state` 폴더에 있는 `halted.json` 파일을
   삭제하세요.
3. `run.bat`을 다시 실행합니다.

**거래소 상태를 직접 확인하기 전에는 절대 `halted.json`을 지우지 마세요.**

### 그 외 오류 메시지가 나왔어요

화면에 나온 오류 문구를 그대로 복사해서 개발자에게 문의하거나, 함께 캡처해서
문의해주세요. 억지로 여러 번 재시도하기보다는, 먼저 거래소 앱에서 실제 상태를
확인하는 것이 안전합니다.

## 8. 자주 묻는 질문

**Q. 연습 모드에서는 정말 돈이 안 나가나요?**
A. 네. 연습 모드(`paper`)는 실제 주문을 전혀 보내지 않고, 컴퓨터 안에서만 가상으로
계산합니다. 다만 시세 조회(현재가, RSI 계산용 데이터)는 실제 인터넷에 연결해서 가져옵니다.

**Q. 프로그램을 끄면 그동안 하던 매매는 어떻게 되나요?**
A. 이미 거래소에 걸어놓은 주문(매수 대기, 익절/손절)은 프로그램을 꺼도 거래소에
그대로 남아있습니다. 프로그램이 꺼져있는 동안에는 그 주문들을 관리해줄 사람이
없다는 뜻이니, 다시 켤 때까지 상황을 스스로 확인해야 합니다.

**Q. "완전 자동"과 "진입만 자동" 중 뭘 선택해야 하나요?**
A. 처음에는 "완전 자동"을 추천합니다. "진입만 자동"은 언제 팔지 스스로 판단하고
거래소에서 직접 주문을 걸 자신이 있을 때만 사용하세요.

**Q. 다른 컴퓨터로 옮기고 싶어요.**
A. 이 폴더 전체를 복사한 뒤(단, `.venv` 폴더는 복사하지 않아도 됩니다), 새 컴퓨터에서
`install.bat`을 먼저 실행하면 됩니다. `.env` 파일에 이미 API 키가 들어있다면 그대로
복사해도 되지만, 유출 위험이 있으니 USB 등 안전한 방법으로만 옮기세요.

## 9. (개발자용) 프로젝트 구조

일반 사용자는 이 항목을 몰라도 됩니다. 코드를 더 살펴보고 싶은 개발자를 위한 참고입니다.

- `main.py` — 봇 전체를 조립해서 실행하는 진입점
- `launcher.py` / `setup_wizard.py` — 비개발자용 대화형 설치/실행 도우미
- `engine/` — 상태 머신, 체결 라우팅, 재시작 복구 등 실행 엔진
- `exchange/` — 거래소 어댑터(`PaperAdapter`=연습용 시뮬레이터, `orangex/`=실거래소 연동)
- `strategy/` — 격자 계산, RSI/ATR 지표 등 순수 계산 로직
- `config/settings.py` — `.env` 스키마
- `docs/` — 개발 과정 기록(API 조사, Phase별 계획/구현 현황)
- `tests/` — 자동 테스트 (`.venv\Scripts\python.exe -m pytest`로 실행)
